Cybersecurity Chatbot
1. Project Overview

This project is a Windows Forms cybersecurity chatbot developed in C#. The chatbot provides users with simple information about cybersecurity topics through a graphical user interface (GUI).

The user can type a question or message into the input box, press the Send button, and receive a response from the chatbot.

The chatbot is designed to demonstrate:

GUI development using Windows Forms

Object-oriented programming

Keyword recognition

Sentiment detection

Randomised responses

Conversation memory

User information capture

Event handling

Basic error handling

Separation of the user interface from chatbot logic

2. Main Features
2.1 Cybersecurity Questions

The chatbot can respond to questions involving topics such as:

Passwords

Phishing

Malware

Antivirus software

Firewalls

Hacking

Two-factor authentication (2FA)

Encryption

VPNs

Social engineering

Privacy

Cybersecurity

For example:

User: What is phishing?

Bot: Phishing is a scam where attackers try to trick you into revealing information.

2.2 Random Responses

The chatbot stores multiple responses for many keywords.

For example:

keywordResponses["password"] = new List<string>()
{
    "Use a long, unique password for every account.",
    "A strong password should be long and difficult to guess.",
    "Consider using a reputable password manager."
};


The chatbot uses the Random class to select one response.

This prevents the chatbot from giving exactly the same response every time.

2.3 Sentiment Detection

The chatbot checks whether the user appears worried or concerned.

Example sentiment words include:

worried
anxious
nervous
concerned
scared
confused
frustrated


For example:

User: I am worried about phishing.

Bot: It's understandable to be concerned. Be careful with unexpected emails or messages asking you to click links or provide passwords.


This allows the chatbot to respond in a more supportive tone.

2.4 Conversation Memory

The chatbot can remember certain information during the current conversation.

It can store:

User's name

Favourite topic

Last cybersecurity topic discussed

For example:

User: My name is John.

User: What is phishing?

Bot: Phishing is a scam where attackers try to trick you into revealing information.

User: Tell me more.

Bot: Check the sender and website address carefully before clicking suspicious links.


The lastTopic field allows the chatbot to understand follow-up questions such as:

Tell me more
Explain more
What else?

3. Project Structure

The project is separated into different files so that the GUI and chatbot logic are not mixed together.

WindowsFormsApp
│
├── Form1.cs
├── Form1.Designer.cs
├── Program.cs
├── ChatEngine.cs
├── Logo.cs
│
└── Voice
    └── aisound.wav

Form1.cs

Form1.cs controls the main graphical user interface.

It is responsible for:

Receiving user input

Handling button clicks

Handling the Enter key

Displaying messages

Displaying the chatbot's response

Playing the greeting sound

Displaying the logo

The form does not contain the main chatbot decision-making logic.

ChatEngine.cs

ChatEngine.cs contains the chatbot's main response logic.

It is responsible for:

Detecting keywords

Detecting sentiment

Remembering information

Selecting random responses

Handling follow-up questions

Providing fallback responses

The main method is:

public string GetResponse(string input)


This method receives the user's message and returns the chatbot's response.

Form1.Designer.cs

This file is automatically generated by Visual Studio.

It contains the configuration and layout information for the Windows Forms controls, including:

Text boxes

Buttons

Picture boxes

Other GUI controls

It is recommended that this file is edited through the Visual Studio Designer rather than manually.

Program.cs

Program.cs is responsible for starting the Windows Forms application.

It launches Form1, which is the main window of the chatbot.

Logo.cs

Logo.cs can be used to keep logo-related functionality separate from the main application logic.

This follows the same principle used with ChatEngine.cs: each class has a specific responsibility.

4. How the Chatbot Works

The chatbot follows this general process:

User enters a message
        ↓
User presses Send
        ↓
Form1 receives the message
        ↓
Form1 calls GetResponse()
        ↓
ChatEngine analyses the message
        ↓
Check for empty input
        ↓
Check for sentiment
        ↓
Check for follow-up questions
        ↓
Check for cybersecurity keywords
        ↓
Check remembered information
        ↓
Use fallback response if nothing matches
        ↓
Response returned to Form1
        ↓
Response displayed in txtLog

5. Important Classes and Methods
ChatEngine

The main chatbot class is:

public class ChatEngine


It contains the chatbot's memory and response information.

GetResponse()
public string GetResponse(string input)


This is the main entry point into the chatbot.

Form1 sends the user's message to this method.

Example:

string response = chatEngine.GetResponse(userMessage);


The returned string is then displayed in the conversation log.

CaptureUserInfo()
private void CaptureUserInfo(string input)


This method looks for information provided by the user.

For example:

My name is Sarah


The chatbot can store:

userName = Sarah


It can also recognise information such as a favourite cybersecurity topic.

GetRandomResponse()
private string GetRandomResponse(List<string> responses)


This method selects one response randomly from a list.

This gives the chatbot more variety.

GetWorriedResponse()
private string GetWorriedResponse(string question)


This method handles messages containing sentiment words.

It combines a supportive statement with a relevant cybersecurity response when possible.

7. Sending a Message

The Send button calls:

private void SendMessage()


The method:

Gets the text from txtUserInput.

Checks whether it is empty.

Displays the user's message.

Sends the message to ChatEngine.

Receives the chatbot's response.

Displays the response.

Clears the input box.

Returns the cursor to the input box.

Example:

string userMessage = txtUserInput.Text.Trim();

string response = chatEngine.GetResponse(userMessage);

txtLog.AppendText(
    "Bot: " + response +
    Environment.NewLine);

8. Using the Enter Key

The chatbot also supports pressing Enter instead of clicking Send.

The relevant event is:

private void txtUserInput_KeyDown(object sender, KeyEventArgs e)


When Enter is pressed, it calls:

SendMessage();


This makes the chatbot easier to use.
